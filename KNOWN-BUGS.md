# Known bugs and evidence gaps

**Baseline date:** 2026-08-20  
**Reference:** OBS Studio 32.2.2  
**Rule:** A failure is recorded here even when it may be environment-specific;
it must be reproduced or explicitly classified before the coordinator closes it.

| ID | Type | Observed behavior | Impact | Reproduction / evidence | Next owner / disposition |
| --- | --- | --- | --- | --- | --- |
| BUG-001 | Quality gate | Strict Clippy fails with `-D warnings` in existing project/benchmark code. | The required verification command cannot be accepted as clean. | `cargo clippy --workspace --all-targets --all-features -- -D warnings`; failures include missing error docs, raw-string hashes, `format_push_string`, boolean conversion, `if_not_else`, and a long test. | Coordinator: create a narrow lint-cleanup packet before feature packets depend on a green gate. |
| BUG-002 | Production output | Native GStreamer production stream tests fail with `ProductionOutput(Native("Element failed to change its state"))`. | Production RTMP/RTMPS/SRT startup is not reliable or not correctly classified as unavailable. | `cargo test --workspace --all-targets`; failures are `production_schemes_create_native_stream_outputs` and `production_only_streams_skip_reference_encoders_and_receive_raw_media`. | Output Agent + Reviewer: distinguish missing local sink/plugin from a pipeline state bug; add capability-aware failure tests and a live fixture. |
| BUG-003 | Test environment / GUI | One GUI test cannot initialize the winit backend because no Wayland compositor is available. | The full GUI binary test target is not green in this managed session. | `cargo test -p obs-rs-gui --bin obs-rs-gui`: 81 pass, `a_failed_output_clears_the_claim_and_offers_guided_recovery` fails while creating a window. `SLINT_BACKEND=testing` does not override the fallback in this build. | QA Agent: provide a compositor-backed CI job or isolate the test from native window creation. |
| BUG-004 | Test environment / capture | X11 and live window tests cannot connect; PipeWire discovery exits 255; no camera is present. | Platform capture/audio parity is unverified on this host. | `obs-rs-linux-check` reports X11/window/camera/PipeWire skip; several live tests are explicitly ignored. | Platform Agents: run the same probes on real X11, Wayland/PipeWire, and device fixtures. |
| BUG-005 | Performance | The release benchmark reports 120/120 single-worker deadline misses and 60/60 multi-worker misses. | The current timing baseline cannot be used as a 60 FPS acceptance result. | `cargo run -p obs-rs-app --bin obs-rs-benchmark --release`; see `PERFORMANCE-BASELINE.md`. | Performance Agent: profile scheduler wait/lateness and separate container scheduling noise from product latency. |
| BUG-006 | Performance architecture | GUI preview performs full canvas GPU readback and then copies RGBA pixels into Slint storage. | A 4K canvas can impose a full-resolution CPU allocation/copy for a small GUI viewport. | `crates/obs-rs-gui/src/preview.rs::render_live_scene` calls WGPU `readback`; `frame_to_image` calls `SharedPixelBuffer::clone_from_slice`. | GPU Agent + UI Agent: implement render-target/presenter split; preserve CPU/reference path for tests. |
| BUG-007 | Canvas behavior | Zoom controls are visual only: the view is always fit-to-window and no zoom/pan state exists. | Core OBS canvas editing workflows are unavailable. | `crates/obs-rs-gui/ui/stage.slint` renders a fit percentage and static minus/plus/dropdown visuals without zoom callbacks. | Canvas Agent: add canonical `CanvasState`, then interaction and snapshot tests. |
| BUG-008 | Canvas behavior | Multi-selection, drag-box selection, snapping, keyboard movement, rotation, and alignment commands are absent. | Transform editing is only a single-item subset of OBS behavior. | No corresponding command/state/callback implementation found in the baseline audit. | Canvas Agent: implement one narrowly scoped capability per work packet. |
| BUG-009 | Dock behavior | Dock state is a flat row of parallel arrays, not a nested split/tab tree; floating geometry is not persisted. | Complex OBS layouts and multi-monitor workflows cannot be reproduced. | `crates/obs-rs-gui/src/callbacks/docks.rs` and `MainWindow` use `panel_order`, `panel_weights`, and `panel_floating`. | Dock Agent: replace with `DockNode` model after canvas/performance packets. |
| BUG-010 | Source parity | The runtime `visible_order` resolves each registered source only once, so repeated scene items referring to the same source collapse to one layer. | Duplicate-source-instance workflows cannot yet match OBS. | Behavior is documented in `crates/obs-rs-gui/src/preview.rs::visible_order`; no instance-level scene identity exists. | Engine Agent: introduce scene-item/source-instance identity before nested scenes/groups. |
| BUG-011 | Filter parity | Project filter kinds/settings can persist even when runtime compilation does not produce an implementation. | A UI/configured filter can appear present while having no effect. | `compile_filter` maps only the current reference filter set; filter persistence tests do not prove runtime application for every kind. | Filter Agent: typed filter graph must return explicit unavailable capability, never silently omit. |
| BUG-012 | Evidence gap | Live screenshots of the main window, Studio Mode, docks, dialogs, menus, projectors, and source windows were not captured. | Visual parity is not yet measured against OBS 32.2.2. | `import -window root` cannot open X server; native GUI test cannot find a Wayland compositor. Settings-page fixtures are available under `artifacts/baseline/screenshots/`. | QA Agent: capture reference/OBS-RS screenshot fixtures on a compositor-backed host. |
| BUG-013 | Build warning | Release binary emits an unused `frame` warning in `EngineSession::push_raw_video`. | Warnings can hide real hot-path drift and contradict the strict verification policy. | `cargo run -p obs-rs-app --bin obs-rs-benchmark --release` reports `crates/obs-rs-engine/src/lib.rs:503`. | Output Agent: resolve or explicitly document the production-feature conditional. |

Environment-limited entries are not automatically product defects, but they stay
open until a real platform run supplies evidence. Product parity must not be
marked complete merely because a test was skipped.
